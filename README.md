# Lumi Control Frontend

Frontend React + Vite baseado no protótipo das 3 telas: Dashboard, Sugestões com IA e Empresas.

## Rodar

```bash
npm install
npm run dev
```

Acesse: http://localhost:5173

## Funcionalidades

- Rotas com React Router DOM
- Sidebar responsiva
- Dashboard com Recharts
- Dados mockados via mockApi
- Busca de empresas em tempo real
- Paginação fake
- Modal de nova empresa, editar, excluir e analytics
- Sugestões com IA com geração fake
- Layout responsivo
